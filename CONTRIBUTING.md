# Contributing

Open an issue describing the new activity or detection proposal, its evidence assumptions, data licensing, and evaluation. Add tests for negative controls and timestamp boundaries. Do not submit personal raw videos, location metadata, license-restricted datasets, pretrained model weights, or generated identification claims without permission and documentation. Run `python -m pytest -q`. Format changed files using Ruff where installed.

The distribution is named `adventure-klip`; the import namespace stays `adventure_intelligence` for compatibility. For model changes, include versioned provenance and synthetic tests plus annotated real-video evaluation before performance claims.
